# ПРАВОЗОР

Проверка земельного участка перед покупкой: кадастровый номер и цель → отчёт о рисках
со ссылками на нормы и путями решения.

## Запуск

Нужен только Docker.

```bash
docker compose up --build
```

Открыть http://localhost:8080, зарегистрироваться, ввести кадастровый номер.

Остановить: `docker compose down` (данные сохранятся; `docker compose down -v` — удалить и базу).

## Как это устроено

| Сервис | Что делает |
|---|---|
| `web` | Nginx: отдаёт фронтенд (React), проксирует `/api`, ограничивает частоту запросов |
| `api` | FastAPI: авторизация (JWT в httpOnly-cookie, Argon2), участки, проверки, PDF |
| `worker` | Celery: считает отчёт в фоне |
| `db` | PostgreSQL 16 + PostGIS: пользователи, проверки, расчёт пересечений |
| `redis` | очередь задач |

Ход проверки (`backend/app/pipeline.py`): участок и граница из НСПД → ЗОУИТ и территориальные
зоны из НСПД → площадь пересечения в PostGIS → правила рисков (`backend/app/rules.py`) → отчёт.

**Правила рисков — черновик разработчика.** Формулировки и ссылки на нормы в `rules.py`
должны проверить юристы.

## Разработка

```bash
docker compose run --rm -e CELERY_EAGER=1 api pytest -q      # тесты бэкенда
cd frontend && VITE_USE_MOCKS=false npm run dev              # фронтенд с горячей перезагрузкой, API — из Docker
```

НСПД отвечает только на запросы с российских IP. Если сервер за границей или за VPN —
задайте прокси в `.env` (см. `.env.example`).

## Чего пока нет

- ИИ-слоя (GigaChat, поиск по базе норм, оцифровка ПЗЗ) — выводы сейчас строятся правилами;
- градостроительных регламентов ПЗЗ — у территориальных зон НСПД отдаёт только реестровый номер;
- выписок ЕГРН, оплаты, HTTPS и развёртывания на сервере, миграций Alembic.
