# ПРАВОЗОР — дизайн-система (MASTER)

Источник: скилл ui-ux-pro-max (`--design-system "legal compliance risk report"`), с ручными поправками ниже.
Реализация токенов — `frontend/src/index.css`.

## Направление

- **Продукт:** B2B SaaS, личный кабинет для девелоперов и юристов: проверка участка → отчёт о рисках.
- **Стиль:** Minimalism & Swiss — чистая сетка, много воздуха, высокая контрастность, без декоративных эффектов.
  Задача интерфейса — доверие и читаемость отчёта, а не «вау-эффект».
- **Плотность:** стандартная (отступы 16–64 px). **Анимации:** минимальные (150–250 мс на hover/focus),
  `prefers-reduced-motion` отключает их полностью.
- **Избегать:** устаревший вид, фиолетово-розовые «ИИ-градиенты», глассморфизм поверх отчёта, эмодзи вместо иконок.

## Цвета (светлая тема)

| Токен | Значение | Назначение |
|---|---|---|
| `--primary` | `#1E3A8A` | Authority navy: основные кнопки, активная навигация, ссылки |
| `--background` | `#F8FAFC` | Фон страницы |
| `--card` | `#FFFFFF` | Карточки |
| `--foreground` | `#0F172A` | Основной текст |
| `--muted-foreground` | `#475569` | Вторичный текст (контраст 7.5:1 на фоне) |
| `--border` | `#CBD5E1` | Границы |
| `--destructive` | `#DC2626` | Ошибки |

**Светофор рисков** — отдельная семантическая шкала, не смешивается с брендом:

| Уровень | Текст | Мягкий фон | Насыщенный (точки, карта) |
|---|---|---|---|
| Низкий | `#166534` | `#DCFCE7` | `#16A34A` |
| Средний | `#92400E` | `#FEF3C7` | `#D97706` |
| Высокий | `#991B1B` | `#FEE2E2` | `#DC2626` |

## Типографика

- **Заголовки:** EB Garamond (serif, юридическая солидность).
- **Текст и интерфейс:** Inter (sans, читаемость, цифры).
- Оба шрифта с кириллицей, подключены локально через `@fontsource` — без запросов к Google Fonts.
- Базовый размер 16 px, межстрочный 1.5; подписи не меньше 12 px.

## Отклонения от рекомендации скилла

| Рекомендация | Решение | Причина |
|---|---|---|
| Body: Lato | Inter | У Lato в Google Fonts нет кириллицы |
| Accent/CTA: `#B45309` (amber) | Не используем | Совпадает с «средним риском» светофора — путало бы смысл цвета |
| Pattern: Trust & Authority (лендинг) | Только для будущего лендинга | Кабинет — рабочий инструмент, а не продающая страница |
| Scroll reveal (GSAP) | Не используем | В кабинете не нужен; меньше зависимостей |

## Правила UX (из базы скилла)

- Риск никогда не передаётся только цветом: всегда иконка + текст («Высокий риск»).
- Ошибки формы — под полем (`FieldError`, `aria-describedby`), при неудачной отправке фокус на первое поле с ошибкой.
- Долгий расчёт отчёта — пошаговый индикатор прогресса; смена статуса объявляется через `aria-live="polite"`.
- Загрузка контента — `Skeleton` по форме будущего контента, а не спиннер.
- Пустые состояния — пояснение + кнопка действия.
- Активный пункт навигации подсвечен; у каждой страницы свой URL (deep links на отчёт).
- Вход: разрешена вставка пароля и менеджеры паролей; кнопка «показать пароль».
- Кликабельные элементы — `cursor-pointer`, видимый focus ring, зона нажатия не меньше 44×44 px на мобильных.
- Адаптив: 375 / 768 / 1024 / 1440 px, без горизонтального скролла.
